# Car Sales & Performance Executive Dashboard
An end-to-end Power BI business intelligence solution designed to track automotive retail performance, monitor year-to-date (YTD) versus month-to-month (MTD) metrics, and evaluate regional dealer sales.
## Project Overview
This dashboard provides executive leadership and sales managers with real-time visibility into automotive revenue streams, inventory movement, and vehicle preferences. It features a custom dark-themed UI with clean visual hierarchy, time-intelligence DAX measures, and interactive navigation between Overview and Details views.
## Key Performance Indicators (KPIs)
•	YTD Total Sales: $371.2M (with MTD Total Sales tracking at $54.28M and a 23.59% growth indicator).
•	YTD Average Price: $28.0K per vehicle (with MTD Avg Price at $28.26K).
•	YTD Cars Sold: 13.3K total units (with MTD Cars Sold at $1.92K units and a 19.73% growth rate).
## Key Insights & Visualizations
•	YTD Sales Weekly Trend: Line chart tracking cumulative weekly sales trajectories, peaking around $14.9M mid-year.
•	Body Style Breakdown: Donut chart segmenting total sales across vehicle types (SUV, Hatchback, Sedan, Passenger, and Hardtop).
•	Color Preference Analytics: Donut chart analyzing sales distribution by vehicle color (Pale White, Black, and Red).
•	Geographical Map (Dealer Region): Interactive Azure/TomTom map visualization mapping dealership sales volumes across different regions (e.g., Pasco, Janesville, Middletown, Austin, Scottsdale).
•	Company Sales Trend Matrix: Detailed data table breaking down performance metrics by manufacturer brand (e.g., Acura, Audi, BMW, Chevrolet, Cadillac) highlighting YTD Avg Price, Units Sold, Total Sales, and % contribution to YTD Total Sales.
## Interactive Filtering & Navigation
•	Dynamic Sidebar Slicers: Instant canvas-wide filtering by Body Style, Dealer Name, Transmission Type, and Engine specifications.
•	Page Navigation: Seamless switching between the main Overview dashboard and deeper Details report pages.
## Tech Stack & Tools
•	Visualization: Microsoft Power BI (Custom Dark Theme UI, DAX Measures, Power Query)
•	Geospatial Mapping: Power BI Map Visuals 
•	Version Control: Git & GitHub
